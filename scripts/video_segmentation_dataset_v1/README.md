# Video Segmentation Dataset v1 Scripts

Script in this folder:

- `train_rfdetr.py` - RF-DETR Seg training wrapper for the dataset in COCO instance-segmentation format

The full video segmentation dataset and its internal preparation helper are not published. The input and export format is documented in [../../docs/datasets/video_segmentation_dataset_v1/input-spec.md](../../docs/datasets/video_segmentation_dataset_v1/input-spec.md). The configs can be validated with the public preview sample in [../../samples/video_segmentation_dataset_v1/all_classes_mini_coco/](../../samples/video_segmentation_dataset_v1/all_classes_mini_coco/README.md).
