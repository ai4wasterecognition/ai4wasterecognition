# Video Segmentation Dataset v1 Scripts

Public script in this folder:

- `train_rfdetr.py` - RF-DETR Seg training wrapper for the local full COCO dataset

The private/local dataset preparation helper is intentionally not published. The public repository documents the required input contract in [../../docs/datasets/video_segmentation_dataset_v1/input-spec.md](../../docs/datasets/video_segmentation_dataset_v1/input-spec.md) and provides only the public training wrapper plus sample configs.
