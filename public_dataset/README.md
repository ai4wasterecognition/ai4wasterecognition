# Public Dataset Placeholder

Place small curated public release files here only if they fit the umbrella-repository model.

Recommended contents:

- `measurements.csv`
- `material_conditions.csv`
- `data_dictionary.csv`

Not every project dataset must live in this folder. Some datasets may instead be documented in `docs/datasets/` and archived externally with a DOI.

Do not place raw radar device logs here unless consortium approval explicitly allows it.
