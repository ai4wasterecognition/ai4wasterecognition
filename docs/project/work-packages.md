# Work Packages

This repository uses the work-package structure from the application as its primary public navigation model.

## Work-Package Map

| WP | Title | Lead | Main public representation in this repository |
| --- | --- | --- | --- |
| KPB1 | Project Management | STU | governance summaries, data-management notes, sustainability notes |
| KPB2 | Tech and AI Research | STU | reviews, technology landscape summaries, methodological notes |
| KPB3 | Laboratory Experiment | Sensoneo | setup summaries, experimental data landing pages, sample assets |
| KPB4 | Data analysis | Optima Ideas | radar, video, and multidetector analysis pages and linked datasets |
| KPB5 | Evaluation | STU | comparisons, recommendations, final summaries, publication index |

## Repository Interpretation

- `KPB1` explains how the project is organized and managed.
- `KPB2` covers research reviews and background analyses that justify the experimental choices.
- `KPB3` covers laboratory setup, detector validation context, and experimental data collection outputs.
- `KPB4` covers analysis outputs built from the collected data.
- `KPB5` covers synthesis, comparison, recommendations, and publications.

## Note on Timing

The application tables contain small inconsistencies in some WP codes and timing fields. For repository structure, the grouping above follows the WP titles and the deliverable naming logic rather than the inconsistent table cells.
