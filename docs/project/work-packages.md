# Work Packages

The repository is organised by the work packages from the project application.

## Work-Package Map

| WP | Title | Lead | Content in this repository |
| --- | --- | --- | --- |
| KPB1 | Project Management | STU | deliverable page only; management deliverables are internal |
| KPB2 | Tech and AI Research | STU | deliverable page only; reports not published yet |
| KPB3 | Laboratory Experiment | Sensoneo | radar dataset v1, CSV previews, measurement setup photos |
| KPB4 | Data analysis | Optima Ideas | multidetector radar dataset with sample photos, radar training and inference code, video segmentation dataset and training code |
| KPB5 | Evaluation | STU | deliverable page and publication index; no publications yet |

## Repository Interpretation

- `KPB1` explains how the project is organized and managed.
- `KPB2` covers research reviews and background analyses that justify the experimental choices.
- `KPB3` covers laboratory setup, detector validation context, and experimental data collection outputs.
- `KPB4` covers analysis outputs built from the collected data.
- `KPB5` covers synthesis, comparison, recommendations, and publications.

## Note on Timing

The application tables contain small inconsistencies in some WP codes and timing fields. For repository structure, the grouping above follows the WP titles and the deliverable naming logic rather than the inconsistent table cells.
