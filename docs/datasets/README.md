# Datasets

This folder is intended for public-facing pages describing individual datasets published under the AI4WasteRecognition project.

Examples:

- radar-derived detectability dataset
- waste-management dataset
- segmentation dataset
- benchmark split descriptions

Recommended pattern:

- one markdown file per dataset
- include scope, version, owners, license, and DOI
- keep large binaries out of GitHub unless they are intentionally small and release-ready
