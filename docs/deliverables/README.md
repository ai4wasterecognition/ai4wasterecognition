# Deliverables and Public Outputs

This folder maps the public repository to the official deliverables listed in the project application.

The repository structure follows the work-package model:

- [KPB1](KPB1.md) - Project Management
- [KPB2](KPB2.md) - Tech and AI Research
- [KPB3](KPB3.md) - Laboratory Experiment
- [KPB4](KPB4.md) - Data analysis
- [KPB5](KPB5.md) - Evaluation

## Normalization Note

The application tables contain a few code inconsistencies. In this repository:

- `D2.x` deliverables are grouped under `KPB2`
- `D3.x` deliverables are grouped under `KPB3`

This grouping follows the deliverable titles and work-package descriptions from the application.

## Access Field

The `Access` column below copies the `V/N` notation from the application table.

- `V` - intended for public dissemination
- `N` - restricted or not intended for direct public dissemination
